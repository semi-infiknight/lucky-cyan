# Operator manual

In programming mode, select a cue and press **F1** to open its exercise. Use **File → Operator manual and tutorials** for the full manual. To begin at the console, open **File → QLab operator guide → Open rehearsal show**. Cue 1 plays a quiet tone, cue 2 fades it, and cue 3 sends an OSC follow. Start with a low monitoring level.

To set up the desk for a dim booth or a bright rehearsal room, [choose an appearance](settings/README.md#choose-a-theme-for-the-desk).
