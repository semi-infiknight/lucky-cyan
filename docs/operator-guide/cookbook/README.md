# Adapt QLab Cookbook techniques to Inkue

The official directory lists 86 projects. This concordance examines individual article text for all 86 entries. Eighty-five contain lessons and one reports a merger. Each row identifies a dependency from the source and an original acceptance exercise for an Inkue rehearsal. The linked references open the publisher’s instructions. ## Record a migration decision

For a technique that depends on external software, record its name, version, license, operating system, message contract or media output, and the cue numbers that use it. Attach a reference recording or receiver trace where possible. A supported primitive such as OSC, MIDI or a Fade cue still needs the end-to-end exercise when a show also uses a tablet layout, AppleScript application control, Audio Unit instrument, Quartz Composer filter, Syphon output or a backup switch.
