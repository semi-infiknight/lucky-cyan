# Learning sources and migration gaps

The current comparison baseline is the fully licensed QLab 5 desk. Earlier manuals help explain the habits a returning programmer brings to it. The links below identify the scope of this review. Index entries and course descriptions establish which topics are taught. The separate reading list identifies the individual lessons examined in developing Inkue exercises. Private courses, unpublished venue manuals and complete video playback are outside this survey. [QLab 5 feature coverage](../coverage/README.md)

## Individual lessons examined

| Reading | How to apply the lesson in Inkue |
| --- | --- |
| QLab 3 cue sequences | Predict which cues share one GO. Rehearse a timed Wait with manual continuation before adding a follow. Observe exactly when the next cue starts. [Cue sequences](https://qlab.app/docs/v3/general/cue-sequences/) · [Inkue programming](../programming/README.md) |
| QLab 4 moving workspaces | A show transfer needs targeted media. Open the collected Inkue show on a destination with the original disk absent, then check its device assignments. [Moving workspaces](https://qlab.app/docs/v4/tutorials/how-to-move-workspaces/) |
| QLab 4 networking | Separate the physical link and IP setup from cue addressing. Begin the OSC workshop on loopback, then repeat it with the venue sender and receiving port recorded. [Networking](https://qlab.app/docs/v4/tutorials/networking/) |
| QLab 4 timecode | Match the receive source and rate, allow pre-roll and confirm each cue at the desk. Practice source loss and relocation on the actual source. [Trigger QLab with timecode](https://qlab.app/docs/v4/tutorials/how-to-trigger-qlab-4-with-timecode/) |
| QLab 4 sound check | Isolate one output at a time and observe where it actually lands. Inkue operators can record both the matrix assignment and the named destination. [Sound check](https://qlab.app/docs/v4/tutorials/sound-check/) · [Inkue audio](../audio/README.md) |
| Cookbook, Main or Backup | Two synchronized desks can duplicate external commands. Assign output ownership and count actual messages on a test receiver during changeover. [Main or Backup](https://qlab.app/cookbook/main-or-backup/) |
| Cookbook, Mixing Stems and Devamps Demystified | Put a musical hold between two unmistakable beats. Request its release mid-pass and listen for the actual exit boundary. The Inkue audio lesson also details imported slice behavior that requires review. [Mixing Stems](https://qlab.app/cookbook/mixing-stems/) · [Devamps Demystified](https://qlab.app/cookbook/devamps-demystified/) · [Inkue musical hold](../audio/README.md) |
| Cookbook, Carts and Remotes | The exercise uses separately displayed carts and a remote interface. Verify each required control surface, focus behavior and simultaneous view on the destination desk. [Carts and Remotes](https://reference.qlab.app/cookbook/carts-and-remotes/) |
| Cookbook, Video Scrubber | The recipe uses an external player and script-driven controls to find and place cue points. Test source-media seeking and the recalled mark individually before accepting a migrated workflow. [Video Scrubber](https://qlab.app/cookbook/video-scrubber/) |

## Product gaps exposed by the exercises

| Operator expectation | Current boundary and test for closure |
| --- | --- |
| Open an older workspace | Import a QLab 3.0.14 `.cues` rehearsal copy and review disarmed groups, audio and external control. Other legacy versions require a separate compatible copy or reconstruction. [Verified archives and migration exercise](../qlab3/README.md) |
| Hand over a live show to a spare | The collected-show manifest verifies identical saved cues and media on the spare. The desk has separate audio, lighting, MIDI, OSC and timecode routes. A single cross-protocol output-ownership switch and automatic takeover remain unverified. A two-desk test must verify exactly one network, MIDI and clock sender and correct physical output ownership before offering a hot-spare workflow. [Verify the spare copy](../standby/README.md) · [Changeover workshop](../workshops/README.md) |
| Reuse a QLab Remote cart or AppleScript recipe | Inkue offers carts, OSC addressing and local assistant control. Importing a cue does not establish that an iOS remote layout, external player script, or utility window works unchanged. Exercise each control the operator calls during the performance and retain the original show's dependency list. [Programming](../programming/README.md) · [Automation](../automation/README.md) |
| Resume a timecoded sequence after a locate | Steady forward playback, a backward locate, a forward jump past a mark and recovery after clock loss are distinct cases. Record observed cue starts on the target receiver and rate before assigning an operator recovery procedure. [Timecode workshop](../workshops/README.md) |

Take the original Inkue exercises at the desk, then capture the machine, show revision, output path and result for each external endpoint. [Rehearse show control and handoff](../workshops/README.md)
